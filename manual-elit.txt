Manual de uso — API de Clientes ELIT
Guía para clientes de ELIT que quieren conectar su tienda o sistema con nuestro catálogo.
Está escrita en lenguaje simple: no hace falta ser programador para entender las primeras
secciones. Si tenés un desarrollador, pasale directamente la sección "Referencia rápida" y las
colecciones de Postman.
1. ¿Qué es la API de ELIT y para qué sirve?
Una API es una forma de que tu sistema (tu tienda online, tu planilla, tu programa de gestión)
le pida datos a ELIT de manera automática, sin que nadie tenga que copiar y pegar a mano.

5. Integraciones con tu tienda o Meta
Además de consultar producto por producto, la API puede darte todo el catálogo en un solo
archivo (CSV), con el formato exacto que necesita cada plataforma. Un archivo CSV es como
una planilla de Excel: lo abrís, o lo subís directo a tu tienda.
Estas descargas se piden desde el navegador o desde tu tienda pegando una dirección web
(URL) que incluye tus credenciales. La estructura es siempre la misma:
Podés agregar los mismos filtros que en productos (por ejemplo &marca=Logitech ).

6. Carrito y cotizaciones (uso avanzado)
Estas funciones son más para quien desarrolla un sistema propio.
6.1 Carrito
El ciclo de un carrito tiene cuatro momentos, y todos están disponibles en la API por token
(con tu user_id y token ): agregar productos, ver lo que hay adentro, vaciar si querés
empezar de nuevo, y confirmar para transformarlo en una orden (nota de venta).
https://clientes.elit.com.ar/v1/api/productos/tiendanube?
user_id=TU_ID&token=TU_TOKEN
1. Descargá el CSV desde esa URL.
2. En Tienda Nube: Productos → Exportar/Importar → Importar por planilla.
3. Subí el archivo y confirmá.
Instalar / conectar tu Tienda Nube con ELIT.
Ver estado de la conexión.
Sincronizar y publicar productos automáticamente.

Todas las operaciones de carrito viajan con las credenciales en el cuerpo (body) de la
consulta, incluida la de vaciar (que es un DELETE con body, no con datos en la URL).
Agregar un producto — POST /v1/api/carrito
Ver el carrito — POST /v1/api/carrito/ver
Vaciar el carrito — DELETE /v1/api/carrito
Confirmar el carrito — POST /v1/api/carrito/confirmar
6.2 Cotizaciones
Permiten armar listas de productos con precio para presupuestar, y consultarlas o modificarlas.
Están disponibles en la API por token (ver la tabla de la sección 7).
En las colecciones de Postman te dejamos ejemplos listos de las operaciones por token. Los
detalles técnicos completos están en el documento API_REFERENCE.md .
Qué hace: suma un producto (con su cantidad) a tu carrito. El sistema elige solo de qué
depósito sale el stock.
Body: user_id , token , code (código de producto), quantity (cantidad). Opcional
warehouse para forzar un depósito.
Ojo: quantity reemplaza la cantidad de ese producto en el depósito, no la suma.
Qué hace: devuelve tus carritos activos con el detalle de productos y los totales (subtotal,
impuestos, envío, total).
Body: user_id , token .
Si no tenés nada en el carrito, responde con items: 0 y details vacío.
Qué hace: vacía el carrito.
Body: user_id , token . Opcional warehouse para vaciar solo un depósito (si no lo
mandás, vacía el carrito correspondiente).
Recordá: es un DELETE que lleva las credenciales en el body, no en la URL.
Qué hace: cierra el carrito y genera la(s) nota(s) de venta. Responde con notas (los
datos de cada nota generada).
Body: user_id , token . Opcional warehouse para confirmar el carrito de un depósito
puntual.
Si no hay un carrito activo, responde con error "No cart available".

8. Preguntas frecuentes y errores comunes
"¿Necesito saber programar para usar esto?"
Para probar en Postman y para las descargas CSV (Meta, WooCommerce, Tienda Nube), no.
Para conectar tu propio sistema a /productos o al carrito, sí conviene tener un desarrollador.

"Me aparece API is disabled ."
La API está temporalmente desactivada para tu cuenta. Escribinos a soporte@elit.com.ar.
"Me aparece Bad Credentials ."
El token es incorrecto o venció. Verificá que copiaste bien el token (sin espacios) y que
corresponde a tu user_id . Si hace falta, generá uno nuevo desde el portal.
"Me aparece Invalid user_id o User not found / Cliente Deshabilitado ."
El número de cliente no es correcto o tu cuenta no está habilitada para la API. Contactá a
soporte.
"Los precios no son los que esperaba."
Los precios salen de tu lista, tu markup y la cotización del dólar vigente. Si algo no cuadra,
consultanos con un ejemplo concreto (código de producto).
"El stock no coincide con la web."
El stock se calcula por depósito según tu cuenta. Revisá stock_total , stock_deposito_cd y
stock_deposito_cliente .
"¿Cada cuánto se actualizan los datos?"
Precios y stock se actualizan de forma continua. Para las tiendas, programá la importación (por
ejemplo, una vez por día) según tu volumen.
"¿Puedo traer solo lo que cambió?"
Sí: usá el filtro actualizacion con una fecha para traer únicamente lo modificado desde ese
momento.
"Se me filtró el token, ¿qué hago?"
Generá uno nuevo desde el portal: el anterior deja de funcionar automáticamente. Después
actualizá el token en Postman y en tu tienda.
¿Dudas? Escribinos a soporte@elit.com.ar. Si sos desarrollador, mirá también
API_REFERENCE.md para el detalle técnico de cada endpoint.
